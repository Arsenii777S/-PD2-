## 10. Структура проекта

```text
project/
├── assets/                       # Игровые ресурсы
│   ├── sprites/                  # Спрайты и изображения
│   ├── animations/               # Анимации персонажей и объектов
│   └── audio/                    # Музыка и звуковые эффекты
├── scenes/                       # Игровые сцены, уровни и меню
├── scripts/                      # Исходный код игры
│   ├── player/                   # Логика управления персонажем
│   ├── enemies/                  # Поведение противников
│   ├── gameplay/                 # Основные игровые механики
│   └── ui/                       # Логика пользовательского интерфейса
├── docs/                         # Документация проекта
│   ├── architecture.md           # Описание архитектуры игры
│   ├── mechanics.md              # Описание игровых механик
│   └── images/                   # Скриншоты игры
│       ├── menu.png              # Главное меню
│       └── gameplay.png          # Игровой процесс
├── README.md                     # Основная информация о проекте
└── .gitignore                    # Файлы, исключённые из Git
```
